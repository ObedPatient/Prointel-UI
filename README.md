# Prointel-UI

ProdIntel UI is a TypeScript React dashboard and public-facing onboarding interface for a manufacturing operations platform.

## What it includes

- Landing pages for marketing and tenant onboarding
- Admin login and company setup flows
- Dashboard pages for operations, suppliers, and company settings
- Reusable UI components built with Radix UI, Tailwind CSS, and Vite

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Radix UI

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
